# BUY-79342 — P6.1 Phase 1 KPI columns

## Columns on `monitoring.v_ceo_kpis`

| Column | Source | Target |
|---|---|---|
| `affiliate_click_intent_page_total_24h` | `affiliate_clicks` where `source=product_card` and `source_page` is an intent-page prefix | ≥50/day |
| `intent_page_r_link_density_avg_24h` | `monitoring.intent_page_r_link_probes` (hourly HTML probe) | ≥5 /r/ links per page |
| `affiliate_revenue_intent_page_total_24h_usd` | `conversions` matched to intent-page clicks by product_id+merchant_id, FX-normalized to USD | ≥$100/day |

The first two columns shipped in BUY-77109. This issue adds the revenue column and the `intent_page_r_click` PostHog event.

## Event capture

- Server: `api/src/analytics/posthog.ts` `trackAffiliateClick` also emits `intent_page_r_click` when pathname/referrer looks like an intent page. Properties: `{page_slug, product_id, merchant_id, ts}`.
- Client: `src/lib/posthog-client.ts` `captureProductCardClick` emits the same event on intent-page cards.

## HogQL (PostHog project `b2097bd8-2aa0-4787-a730-b4f50022d1e6`)

```sql
SELECT count() AS affiliate_click_intent_page_total_24h
FROM events
WHERE event = 'intent_page_r_click'
  AND timestamp >= now() - INTERVAL 24 HOUR
```

Dashboard: PostHog project 415112 / UUID `b2097bd8-2aa0-4787-a730-b4f50022d1e6` → Insights → new HogQL insight with the query above. Live readback: `GET https://monitoring.buywhere.ai/api/monitoring/ceo_kpis?window=24h`.
