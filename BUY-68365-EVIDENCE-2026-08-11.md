# BUY-68365 — Gaming laptop search ranks an internal SSD as #2

**Status:** Reproduction CONFIRMED live. Root cause: client-side `rankProduct` / `isAccessoryProduct` in `src/app/search/SearchResultsClient.tsx` only catches accessory KEYWORDS in the title (skin/case/cover/backpack...) and never checks the product's `category` field. The Firecuda's title does not contain any accessory keyword, so the function returns `false` → it gets the full +25 "not an accessory" bonus, ties the GIGABYTE laptops on (image + price) and ranks #2.

## Mirror of BUY-63953

This is the same pattern as the laptop-fallback AND-bug (memory: `buywhere-buyer-63953-laptop-fallback-and-bug.md`): the FTS engine uses positive-token matching ("gaming" OR "laptop") and the client-side ranker boosts without an explicit category filter. ## Suggested fix (pending PR review)

Mirror the same pattern as the laptop fallback fix and PR #426 (BUY-67973) and PR #430 (BUY-67976): add a category-mismatch detector at the top of `rankProduct`. When the query contains a complete-device token (laptop, notebook, macbook, phone, smartphone, iphone, monitor, tv, television, refrigerator, dishwasher, playstation, xbox), any product whose `category` does NOT match a known primary-device category should be heavily demoted (or filtered out).

Sketch:

```ts
const COMPLETE_DEVICE_TOKENS = /\b(laptop|notebook|macbook|phone|smartphone|iphone|monitor|television|tv|refrigerator|dishwasher|playstation|xbox)\b/i;

const PRIMARY_CATEGORIES_BY_DEVICE: Record<string, string[]> = {
  laptop:   ['laptops', 'computers', 'notebooks', 'chromebooks', 'gaming laptops'],
  phone:    ['smartphones', 'mobile phones', 'cell phones', 'phones', 'iphones', 'android phones'],
  monitor:  ['monitors', 'computer monitors', 'displays'],
  tv:       ['televisions', 'tvs', 'tv, video & home audio'],
  ...
};

function isCategoryMismatched(query: string, product: SearchCardProduct): boolean {
  const deviceMatch = query.toLowerCase().match(COMPLETE_DEVICE_TOKENS);
  if (!deviceMatch) return false;
  const device = deviceMatch[1];
  const allowed = PRIMARY_CATEGORIES_BY_DEVICE[device];
  if (!allowed) return false;
  const cat = (product.category || '').toLowerCase();
  return cat && !allowed.some(a => cat.includes(a));
}
```

Then in `rankProduct`, subtract a heavy penalty (e.g. -200) for `isCategoryMismatched`.
